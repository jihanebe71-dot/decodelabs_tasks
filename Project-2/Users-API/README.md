# Users API

## Description
Users API is a RESTful API built with Node.js and Express.js. It allows users to be created, displayed, updated, and deleted.

## Technologies Used
- Node.js
- Express.js
- JavaScript

## Features
- GET: Retrieve all users.
- POST: Create a new user.
- PUT: Update an existing user.
- DELETE: Delete a user.
- Email validation.
- Error handling.

## Installation

1. Clone or download the project.
2. Open the project folder in VS Code.
3. Install dependencies:

```bash
npm install
```

## How to Run

Start the server:

```bash
node server.js
```

The server runs at:

`http://localhost:3000`

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/users` | Get all users |
| POST | `/api/users` | Create a user |
| PUT | `/api/users/:id` | Update a user |
| DELETE | `/api/users/:id` | Delete a user |
