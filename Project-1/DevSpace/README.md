# DevSpace — Developer Portfolio

A bilingual (English/French), responsive developer portfolio built with **HTML5, CSS3 and vanilla JavaScript**. No frameworks are used.

## Features
- Responsive, mobile-first layout
- Semantic HTML5 sections
- CSS Grid, Flexbox and media queries
- English/French language switcher
- Mobile navigation menu
- Project, skills, about and contact sections
- Accessible labels and reduced reliance on images

## Project structure
```text
DevSpace/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to run
1. Download or clone this repository.
2. Open the `DevSpace` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
4. Resize the browser or use Developer Tools to test mobile, tablet and desktop layouts.

No build command or package installation is required.

## Personalize before publishing
In `index.html`, replace:
- `Your Name` with your real name.
- `your.email@example.com` with your real email address.
- The GitHub and LinkedIn profile links with your own profile URLs.
- The sample project concepts with your real completed projects and repository links.
- The sample statistics and skills with accurate information about yourself.

The project cards are clearly marked as concepts; do not present them as completed client work.
