# DecodeLabs Tasks – Projects Portfolio

Welcome to my DecodeLabs projects repository! This repository contains three projects developed during my internship.

## 📁 Projects

### Project 1 – DevSpace
A personal developer portfolio website.

**Technologies:** HTML5, CSS3, JavaScript

**Run the project:**
- Open `Project-1/DevSpace/index.html` in your browser.

### Project 2 – Users API
A REST API for managing users with CRUD operations.

**Technologies:** Node.js, Express.js

**Run the project:**
```bash
cd Project-2/Users-API
npm install
node server.js
```

Server: `http://localhost:3000`

### Project 3 – Users API with MongoDB
A REST API connected to MongoDB for managing users.

**Technologies:** Node.js, Express.js, MongoDB, Mongoose

**Run the project:**
```bash
cd Project-3/Users-API
npm install
node server.js
```

Make sure MongoDB is running and the database connection is configured correctly.

Server: `http://localhost:3000`

## 🛠️ Requirements

- Node.js and npm
- MongoDB (for Project 3)
- Visual Studio Code
- Web browser
